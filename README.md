# ESMI website

Website of ESMI, Eboat System Merchandising Incorporated: solar-electric modular boats in the Philippines.
Published at https://www.eboatsystem.com (Vercel, static site, no build step).

This repository holds the exported site only. It is generated from the working project with
`python -I scripts/export_site.py <this folder>`, which follows every page linked from `index.html`
and copies the pages and assets they use.
